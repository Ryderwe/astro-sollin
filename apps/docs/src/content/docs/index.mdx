## 核心能力

<CardGrid stagger>
  <Card title="多样播放界面">
    近期版本加入了 AM 高级版、素雅风、微信聊天等多种播放界面，并持续优化歌词与动画表现。
  </Card>
  <Card title="歌词与音质增强">
    支持 TTML、逐字歌词、罗马音、翻译、自定义字号颜色，以及音质徽章和音质切换。
  </Card>
  <Card title="下载与本地管理">
    支持下载命名规则、自定义备份、WebDAV、标签编辑器、本地音乐整理与导入能力。
  </Card>
  <Card title="发现与歌单体验">
    覆盖推荐歌单、排行榜、歌手搜索、评论展示、歌单分页、快捷入口与多种平台切换方式。
  </Card>
</CardGrid>
