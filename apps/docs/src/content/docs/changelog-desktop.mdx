- 新增迷你模式切换。

- 完善歌词播放与歌单广场功能。
- 新增封面背景主题构建能力，并优化歌词面板背景。

- 新增屏蔽规则。
- 新增音质徽章展示。
- 新增歌单分页加载。

- 统一歌单库与备份处理逻辑。
- 精简并修复核心逻辑，提升整体稳定性。

### 问题修复

- 修复点击下载后没有即时反馈的问题。

## v1.2.5

- 发布时间：`2026-03-27`
- Windows：`1.2.5`
- macOS：`1.2.5`

- 新增本地音乐专区、本地歌单与本地收藏。
