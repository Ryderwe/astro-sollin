## v1.3.9

- 发布时间：`2026-04-30`
- Android：`1.3.9 (10009)`
- iOS：`1.3.9 (10009)`

### 新功能

- 推出全新 AM 高级版播放界面，动画更细腻，并支持 TTML。
- 新增素雅播放界面。
- 所有播放界面启用全新音质徽章。
- 新增发现详情页样式设置。
- 侧边栏新增歌单快捷入口，并支持在界面布局中自定义显示内容。
- 新增歌手搜索，支持 `wy`、`kg`、`qq`。
- 支持自定义下载文件命名规则。
- 新增支持修改主句、副句、罗马音、翻译字号大小。
- 新增联系管理员消息功能。
- 新增网易云心动模式与哔哩哔哩认证实验支持。
- Navidrome 歌曲列表改成分页加载。

### 优化与修复

- 优化播放界面歌词间距与分行逻辑。
- 优化 Navidrome 横屏显示。
- 修复本地 FLAC 解码切歌卡顿问题。
